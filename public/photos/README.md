# Photographs

Drop image files in here and they appear on the site automatically. There is no
code change and no list to update: the folders are read at build time and
matched to categories and products by filename.

```
categories/<category-slug>.jpg     shown on the category index and the category page
products/<product-slug>.jpg        shown beside each product
site/hero.jpg                      the home page hero
site/about.jpg                     the about page
```

Accepted formats: .jpg, .jpeg, .png, .webp, .avif. Where no photograph exists,
the site falls back to a typographic tile, so a partly photographed site still
looks deliberate rather than broken.

## Before adding anything

Every photograph on this site needs to be one of three things:

1. Taken by or for AfriLynq, with a written release from any identifiable
   person in it.
2. Licensed stock, with the licence covering commercial use on a website.
3. Supplied by a listed supplier, with their written permission to publish it.

Photographs of identifiable people carry image rights as well as copyright, and
this is a United Kingdom site. Pulling pictures of farmers from a search engine
is the one shortcut that can turn into a real claim, and the person in the
photograph has rights independent of whoever took it.

Practical sizes: hero about 2000 px wide, category and product tiles about
1200 px wide, all in landscape. Compress before adding.
